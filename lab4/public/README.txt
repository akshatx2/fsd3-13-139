BRIGHTPATH TUITION CLASSES WEBSITE
===================================

Files:
- index.html       Home page
- register.html    Registration page
- login.html       Login page
- courses.html     Courses and pricing details
- feedback.html    Feedback page
- style.css        Shared responsive stylesheet

All five HTML pages are linked through the navigation bar and footer.
Font Awesome icons are loaded from CDN for the social media and interface icons.

Open index.html in a browser to start.

Note: Registration/login/feedback forms are front-end demo forms. They show a
confirmation message but do not connect to a database or authentication server.
Replace the sample contact details and social links with your actual details.
